# CollegeCompass 🎓

A modern engineering college discovery platform that helps students explore colleges, compare institutes, and predict admission chances based on entrance exam ranks.

## Features

- 🔍 Search and filter engineering colleges
- 🏫 Explore IITs, NITs and private institutes
- ⚖️ Compare colleges side-by-side
- 🎯 College predictor based on entrance ranks
- 📱 Fully responsive mobile design
- 📄 Detailed college information pages
